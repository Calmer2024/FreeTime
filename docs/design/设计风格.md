# DrillKnowledge 设计风格

> 用于指导新页面和新组件维持 DrillKnowledge 的统一品牌表达。设计决策优先级：内容可读性与任务效率 > 清晰层级 > 品牌一致性 > 装饰效果。

## 1. 品牌关键词

**克制、理性、轻盈、精密、可信。**

DrillKnowledge 是知识提取与阅读工具，不是内容娱乐平台。界面应像一张组织良好的白色工作台：信息密度高但不拥挤，层级清晰但不喧闹，交互反馈明确但不过度表演。

## 2. 视觉原则

### 内容先于容器

- 首先建立标题、正文、元数据的排版层级，再添加容器。
- 能用留白和细分割线解决的问题，不新增卡片。
- 同一视图最多形成“页面 / 主面板 / 内容块”三层容器，避免卡片套卡片。

### 中性色是品牌色

- 主操作使用近黑色，不为“品牌感”额外引入高饱和色。
- 大面积背景保持白色或极浅灰；正文对比稳定，辅助信息主动退后。
- 绿色、黄色、红色、蓝色仅表达语义，不作为装饰。

### 精密而不冰冷

- 使用细线图标、稳定数值宽度、整齐网格体现工具感。
- 使用 9/12/18px 的柔和圆角和低透明阴影减轻机械感。
- 文案直接、自然、简短，避免营销语、感叹号和拟人化加载提示。

### 安静的反馈

- hover 只提高一级对比度；active 使用极轻缩放；展开使用短距离淡入。
- 避免弹跳、霓虹光、长距离位移、连续呼吸动画和无意义自动播放。
- 状态变化应发生在用户关注的位置，并保持周围布局稳定。

## 3. 页面构图

- 顶部栏保持轻薄，使用半透明白和模糊与内容分层；核心输入或命令入口居中。
- 主内容限制最大宽度，桌面常规为 `1200px`，超宽屏最多 `1440px`，两侧保留呼吸空间。
- 桌面优先“左侧上下文 / 右侧主阅读”的双栏布局；窄屏自然切换为单列。
- 主要阅读区可以独立滚动，导航、页签和关键操作保持可见；避免整页多处争夺滚动。
- 每个区块只有一个清晰主标题；关联操作靠右并与标题基线对齐。

## 4. 信息层级

统一使用以下五级层次：

1. **主要结论**：最大字号、主要文字色，是当前页面首先要读的内容。
2. **区块标题**：17px 左右，用细图标辅助定位。
3. **正文内容**：14–16px、宽松行高，保证长文阅读。
4. **辅助说明**：11–13px、次级文字色。
5. **元数据**：9–10px、三级文字色；数值可使用等宽字体。

不要仅依靠字号区分层级；同时使用字重、颜色、间距和分割线。单一区域内通常不超过 3 个字重。

## 5. 新组件设计方法

开发新组件前依次完成：

1. 明确组件的唯一主任务，以及默认、hover、focus、active、loading、success、error、disabled、empty 状态。
2. 从 [组件规范.md](./组件规范.md) 选择最接近的既有结构；优先组合，不创建视觉近似的新变体。
3. 只使用 [DesignToken.md](./DesignToken.md) 中的颜色、圆角、字体、阴影和动效节奏。
4. 先验证长中文、英文 URL、错误堆栈、空数据和高倍文本缩放，再处理理想内容。
5. 在 `1240 / 800 / 600px` 关键宽度和低高度桌面窗口下验证布局。
6. 最后检查键盘操作、可访问名称、焦点、对比度和减少动态效果设置。

若新需求无法由现有 Token 表达，应先补充语义 Token，再在组件中使用；不得直接为单个组件引入近似灰色、圆角或阴影。

## 6. 推荐与禁用模式

| 推荐 | 禁用 |
| --- | --- |
| 白色画布、浅灰弱分区 | 彩色渐变大背景、玻璃效果滥用 |
| 单一近黑主操作 | 同一区域多个高对比主按钮 |
| 细边框 + 轻阴影 | 粗边框 + 重阴影 + 高饱和底色叠加 |
| 小面积语义色 | 用整张卡片红/绿底表达状态 |
| 原地编辑和确认 | 普通 CRUD 打开 Modal 或确认气泡 |
| 轻微淡入、短距离位移 | 弹跳、旋转入场、长时间装饰动画 |
| Lucide 线性图标 | Emoji、彩色图标、混用多套图标 |
| 简短明确的中文文案 | 营销化、拟人化、含糊的操作文案 |
| 稳定操作槽和骨架尺寸 | 加载或状态切换导致内容跳动 |

## 7. 文案与图标

- 按钮使用“动词 + 对象”：`复制全文`、`下载封面`、`清空记录`；空间紧张且上下文明确时可简化为动词。
- 状态使用客观描述：`处理中`、`已完成`、`提取失败`；不要使用“马上就好”“正在努力”等拟人表达。
- 危险操作必须写清对象，确认按钮的无障碍名称应为 `确认删除任务`，不能只写 `确认`。
- 图标用于增强识别而非替代含义；不熟悉的图标应带文字或 Tooltip。

## 8. 品牌一致性自检

完成新 UI 后，确认以下问题均可回答“是”：

- 第一眼能否识别主任务，而不是先看到装饰和容器？
- 页面是否主要由白、浅灰、近黑组成，语义色是否克制？
- 圆角、阴影、图标线条和交互节奏是否与现有界面一致？
- 信息密度是否高效，同时保留稳定的阅读行高和区块间距？
- 所有状态是否就地反馈且不造成布局跳动？
- 窄窗口、长文本、键盘操作和减少动态效果是否仍可用？

只要其中任一项为“否”，组件就还没有达到 DrillKnowledge 的品牌完成度。
