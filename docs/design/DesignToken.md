# DrillKnowledge Design Token

> 适用范围：DrillKnowledge Web / Desktop UI。本文从当前界面实现中提炼品牌基础变量；新增样式应优先引用 Token，避免散落硬编码。当前实现以 `apps/media-extractor/static/app.css` 的 `:root` 为准。

## 1. 设计基调

- 明亮、安静、理性：以白色和中性灰为主，不使用装饰性渐变或高饱和品牌色。
- 内容优先：颜色用于建立层级，状态色仅在图标、文字、徽标和浅色背景中小面积出现。
- 轻量层次：使用细边框、柔和阴影和少量毛玻璃表达容器关系。

## 2. 颜色

### 基础与内容色

| Token | 当前值 | 用途 |
| --- | --- | --- |
| `--shell` | `#ffffff` | 应用最外层背景 |
| `--canvas` | `#ffffff` | 内容画布 |
| `--surface` | `#ffffff` | 卡片、控件背景 |
| `--surface-solid` | `#ffffff` | 必须不透明的浮层 |
| `--surface-raised` | `#ffffff` | 选中项、抬升层 |
| `--surface-muted` | `#f6f6f7` | 次级区域、悬停、弱强调 |
| `--ink` | `#1d1d1f` | 标题、正文、主要图标 |
| `--ink-secondary` | `#5f5f63` | 说明文字、次级操作 |
| `--ink-tertiary` | `#8e8e93` | 元数据、占位、弱图标 |
| `--line` | `rgba(29, 29, 31, .09)` | 默认分割线和边框 |
| `--line-strong` | `rgba(29, 29, 31, .15)` | 强调边框、可交互轮廓 |

### 操作与状态色

| Token / 语义 | 前景 | 浅背景 | 用途 |
| --- | --- | --- | --- |
| `--action` | `#1d1d1f` | `--action-soft: #f1f1f2` | 主操作、总计、当前进度 |
| `--action-hover` | `#000000` | — | 主操作悬停 |
| `--danger` | `#9a5a53` | `--danger-soft: #f3e8e6` | 删除、错误 |

| 警告 / 混合 | `#8a6a2d` | `#f5f0e2` | 混合结论、需注意 |
| 等待 | `#5f6670` | `#eceff2` | 未决、等待 |
| 信息 | `#245c76` | `#e2f2fa` | 外部信息、Web 来源 |
| `--focus` | `rgba(29, 29, 31, .14)` | — | 键盘焦点轮廓 |

状态色必须成对使用“前景 + 浅背景”，不得用高饱和纯色铺满大面积容器。正文链接默认仍使用 `--ink`，不引入蓝色品牌色。

## 3. 字体与排版

```css
--font-sans: -apple-system, BlinkMacSystemFont, "SF Pro Text",
  "PingFang SC", "Microsoft YaHei UI", "Segoe UI", sans-serif;
--font-mono: "SFMono-Regular", "Cascadia Code", ui-monospace, monospace;
```

| 层级 | 字号 | 字重 | 推荐行高 | 使用场景 |
| --- | ---: | ---: | ---: | --- |
| 展示标题 | `21px` | `650–700` | `1.3–1.35` | 结论、文章一级标题 |
| 区块标题 | `17px` | `650–660` | `1.35–1.5` | 主要内容分区 |
| 强调正文 | `16px` | `400–600` | `1.85` | 摘要 |
| 正文 | `14px` | `400–500` | `1.8–1.95` | 阅读内容 |
| 组件文本 | `11–13px` | `500–650` | `1.45–1.7` | 按钮、卡片、说明 |
| 元数据 | `9–10px` | `500–600` | `1.3–1.6` | 标签、时间、技术指标 |

- 中文正文使用无衬线字体；耗时、计数、编号和结构化数据使用 `--font-mono`。
- 数值列表使用 `font-variant-numeric: tabular-nums`，避免刷新时宽度跳动。
- 标题可使用 `-.015em` 的轻微负字距；正文不应使用明显字距。

## 4. 尺寸、间距与圆角

基础间距以 `4px` 为主网格，紧凑组件允许 `2px` 半步，优先使用：`4 / 6 / 8 / 10 / 12 / 14 / 16 / 20 / 24 / 30 / 34 / 40 / 48px`。

| Token | 值 | 用途 |
| --- | ---: | --- |
| `--radius-sm` | `9px` | 小按钮、列表项、提示块 |
| `--radius-md` | `12px` | 内容卡片、媒体框 |
| `--radius-lg` | `18px` | 页面主面板、模态框 |
| 胶囊圆角 | `999px` | 搜索框、标签、徽标 |
| 小按钮高度 | `26–34px` | 图标、次级操作、页签 |
| 标准输入高度 | `38–44px` | 输入框、命令栏 |
| 最小可触区域 | `34 × 34px` | 常规图标按钮；紧凑列表可降至 `27px` |

同一组件内部优先用 `6–12px` 间距；卡片内边距使用 `12–20px`；主要内容区使用 `20–34px`。

## 5. 边框、阴影与层级

```css
--shadow-panel:
  0 1px 1px rgba(25, 27, 24, .04),
  0 12px 36px rgba(25, 27, 24, .055);
```

| 层级 | 建议样式 | `z-index` |
| --- | --- | ---: |
| 普通内容 | `1px solid var(--line)`，可无阴影 | 默认 |
| 粘性标题 / 顶栏 | 白色或半透明白 + blur | `3 / 100` |
| Dropdown / Popover | `rgba(255,255,255,.97)` + `0 18px 55px rgba(24,26,23,.16)` | `1000` |
| Toast / Notice | 实体浅背景 + 中等阴影 | `1100` |
| Modal | 遮罩 + `0 24px 80px rgba(24,26,23,.24)` | `1200` |

毛玻璃仅用于顶部栏和悬浮层；普通内容卡片保持接近实体白色，避免多层透明造成内容发灰。

## 6. 图标、动效与滚动条

- 图标统一使用 Lucide 线性图标，默认 `16px`、`stroke-width: 1.75`；紧凑组件 `12–14px`，主操作 `18px`。
- 常规状态过渡为 `140–200ms ease`；内容展开使用 `280–320ms cubic-bezier(.2,.75,.25,1)`。
- 按压反馈使用 `scale(.96–.985)`，不得引发布局位移。
- 加载旋转统一 `.8s linear infinite`；骨架闪烁统一 `1.2s linear infinite`。
- 尊重 `prefers-reduced-motion: reduce`，将非必要动画和过渡缩短到 `.01ms`；加载旋转可保留。

滚动条 Token：

```css
--scrollbar-thumb: rgba(82, 84, 88, .24);
--scrollbar-thumb-hover: rgba(52, 54, 58, .42);
```

滚动条宽高 `7px`、轨道透明、滑块胶囊圆角、`2px` 透明边框并使用 `background-clip: content-box`；内容区使用 `scrollbar-gutter: stable` 或稳定宽度，避免出现滚动条时页面横跳。

## 7. 响应式基准

- `≤1240px`：顶部导航与搜索区改为纵向布局，结果区由左右分栏改为上下结构。
- `≤800px`：内容收窄、结果单列、页签允许横向滚动。
- `≤600px`：隐藏非必要图标或页签文字，减少内容内边距。
- 高度 `≤620px` 且宽度 `≥1241px`：压缩顶部与结果区间距。
- 宽度 `≥1800px` 且高度 `≥900px`：内容最大宽度可扩至 `1440px`。

新增断点前应优先验证现有断点能否解决问题，避免形成组件私有断点。
