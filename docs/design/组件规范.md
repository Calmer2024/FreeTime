# DrillKnowledge 组件规范

> 本文规定高复用组件的外观与交互。具体色值、字号、圆角和层级引用 [DesignToken.md](./DesignToken.md)；通用浮层与 CRUD 约束同时遵循 [ui-ux-guidelines.md](./ui-ux-guidelines.md)。

## 1. 通用规则

- 控件继承 `--font-sans`，图标使用 Lucide；不要混用填充图标、Emoji 或多套图标库。
- 所有可交互元素必须有 `hover`、`active`、`focus-visible`、`disabled` 状态。
- 键盘焦点统一为 `3px solid var(--focus)`，`outline-offset: 2px`；不得仅靠颜色变化表示焦点。
- 图标按钮必须提供准确的 `aria-label`；状态切换同步更新 `aria-expanded`、`aria-selected` 等属性。
- 异步操作只禁用触发操作及其所属条目，不锁定无关区域。

## 2. 按钮

| 类型 | 规格 | 默认样式 | 交互 |
| --- | --- | --- | --- |
| 主图标按钮 | `44 × 44px`，圆形，图标 `18px` | 白字、`--action` 背景、无边框 | hover 使用 `--action-hover`；active 缩放 `.985`；loading 透明度 `.55` |
| 主文字按钮 | 高 `32–40px`，圆角 `8px` | 白字、`--action` 背景 | hover 加深；loading 显示旋转图标并禁用 |
| 次级按钮 | 高 `32–40px`，水平内边距 `11–14px` | `--surface` 背景、`--line` 边框、次级文字 | hover 提升文字和边框对比度 |
| 图标按钮 | 常规 `34 × 34px`，圆角 `9px` | 透明背景、弱图标色 | hover 使用 `--surface-muted`；危险操作使用 `--danger-soft` |
| 紧凑操作 | `27 × 27px` 或高 `27px` | `7px` 圆角、`--line` 边框 | 仅用于任务等高密度列表 |

- 一个操作组只保留一个主按钮；其他操作使用次级或图标按钮。
- 危险按钮默认克制，仅图标/文字使用 `--danger`，悬停时出现 `--danger-soft` 背景。
- 删除采用原地二次确认：原操作槽切换为“确认 / 取消”，操作槽宽度固定，不使用额外弹窗或气泡。
- 禁用态需降低透明度并移除点击能力；加载态使用 `cursor: wait`，且保留原尺寸。

## 3. 输入框、选择器与命令栏

- 标准输入高度 `38–44px`，背景 `--surface`，文字 `--ink`，占位文字使用三级灰。
- 独立输入框使用 `1px solid var(--line)`、`9px` 圆角、左右内边距 `12px`。
- 聚焦时边框变为 `--action`，外加 `3px` 弱焦点环；不要改变控件尺寸。
- 命令栏使用白色胶囊容器、`6px` 内边距和柔和阴影；内部字段无边框，`focus-within` 仅以 `--surface-muted` 提示当前区域。
- 选择器与相邻输入以 `24px` 高的 `--line-strong` 竖线分隔；箭头 `14px`，展开后旋转 `180deg`。
- 错误信息紧邻输入框下方，使用 `--danger`、`11–12px`；不得只将边框变红而不提供文字说明。

## 4. 卡片与面板

| 组件 | 圆角 | 内边距 | 边框 / 背景 |
| --- | ---: | ---: | --- |
| 页面主面板 | `18px` | 由内容分区控制 | `--surface` + `--line` + `--shadow-panel` |
| 内容卡片 | `12px` | `14–20px` | `--surface` 或极浅暖白 + `--line` |
| 列表项 | `9px` 或与父面板融合 | `9–14px` | 白色；用分割线组织密度 |
| 弱提示块 | `9px` | `12–14px` | `--surface-muted`，通常无阴影 |

- 卡片层级主要由留白、细边框和浅背景表达；禁止同时使用粗边框、重阴影和高对比底色。
- 状态卡片保持白色，仅用图标、文字、必要的浅色边框/徽标表达状态。
- 列表中标题最长两行，元数据单行省略；为操作区预留固定宽度，状态切换不得导致位移。
- 可点击卡片 hover 只能轻微改变背景或媒体缩放（建议不超过 `1.025`），不得整体大幅上浮。

## 5. 页签、标签与徽标

- 页签组使用 `--surface-muted` 背景、`3px` 内边距、`10px` 圆角，项间距 `3px`。
- 页签高 `32–34px`、圆角 `8px`；默认三级文字，hover 次级文字，active 为主要文字 + 白色背景 + 极浅阴影。
- 标签 / 徽标使用胶囊圆角，字号 `9–11px`，内边距约 `4–5px 8–9px`。
- 标签用于分类和短状态，不承载句子；同一区域尽量不超过 3 种颜色。
- 移动端空间不足时优先隐藏页签文字、保留图标与无障碍名称。

## 6. Dropdown、Popover、Tooltip 与 Modal

- Dropdown / Popover 必须脱离普通文档流，不得撑开或切开父卡片；与触发器间距 `6–10px`。
- 浮层使用近乎不透明白、`--line` 边框、实体阴影，层级 `1000`；点击外部或按 `Escape` 关闭。
- Dropdown 选项字号 `13px`、内边距 `8px 12px`、圆角 `6px`；hover 与 active 使用 `--surface-muted`。
- Tooltip 使用深灰背景、浅色文字、字号 `11px`、最大宽度 `280px`；仅补充说明，不承载必须阅读的信息。
- Modal 仅用于无法原地完成的独立流程；层级 `1200`，卡片最大宽度约 `520px`。普通 CRUD 禁止使用 Modal。

## 7. 滚动区域

- 页面只允许指定内容容器滚动；桌面主框架保持无全局滚动。
- 嵌套滚动区统一 `7px` 细滚动条、透明轨道、胶囊滑块，使用 Design Token 中的滚动条颜色。
- 使用 `overscroll-behavior: contain` 防止滚动穿透；横向溢出优先换行或省略，仅页签等连续控件允许横向滚动。
- 固定或粘性标题必须使用实体/高不透明背景，避免下层文字透出。

## 8. 加载、空、成功与错误状态

- 加载：小范围操作使用 `14–15px` 旋转图标；内容加载使用骨架屏，保留最终布局尺寸。
- 空状态：三级文字 + 线性图标，居中但不夸张，不使用大插画抢占内容。
- 成功：绿色只用于图标、文字、徽标或短暂按钮反馈。
- 错误：错误文字必须可读；任务错误信息独占第二行、最多两行，完整信息放入 `title`。
- Toast 仅用于短暂全局反馈；与某条记录相关的错误必须显示在该记录内。

## 9. 验收清单

- 尺寸、颜色、圆角是否引用既有 Token？
- 键盘能否访问，焦点是否清晰，图标按钮是否有名称？
- hover / active / loading / disabled 是否不改变布局尺寸？
- 删除与编辑是否原地完成，列表操作槽是否稳定？
- 长标题、错误文本和窄窗口是否经过溢出验证？
- 是否支持 `prefers-reduced-motion`？
